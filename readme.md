# Spice Corner - Restaurant Website

A multi-page, responsive restaurant website (demo project) built with
HTML, CSS and JavaScript.

## Live Demo
https://resturant-website-modern.vercel.app

## Pages
- Home: hero section, food categories, popular items, offer, reviews
- Menu: food items by category
- Order: order form
- About
- Contact

## Features
- Responsive layout with mobile menu
- Category links to menu sections
- Clean, semantic HTML structure

## Tech Used
HTML5, CSS3, JavaScript | Hosted on Vercel

## Project Structure
css/ | js/ | images/ | index.html, menu.html, order.html,
about.html, contact.html

## Note
Restaurant name, reviews and contact details are placeholders for demo purposes.
